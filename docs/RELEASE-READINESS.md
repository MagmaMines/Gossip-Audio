# Release readiness

This project is not yet certified production- or commercial-ready. The 1.5.0 debug build passed JVM tests and Android 10 x86_64 emulator tests for the bundled and downloaded neural voices, the shared-pack download button and navigation, automatic-selection UI, WAV round-trip and MP3 encoding ([CI run](https://github.com/MagmaMines/Gossip-Audio/actions/runs/41393699322)). The emulator generated the WAV sample in `dist/` and found no hard-clipped PCM samples. An Android emulator can check that the neural model loads and generates non-silent audio, and that WAV/MP3 data is created, but those checks cannot measure naturalness, pronunciation or freedom from every artifact. Listen to the generated sample and test on real phones, speakers and headphones before release.

Before distribution: test language handling, long text, storage and permissions; verify WAV, MP3 and M4A output in independent players; test playback interruptions, notifications, reminders, accessibility, themes and upgrade paths; audit privacy and model/runtime/eSpeak license terms; sign with a private production key; and complete Play policy, security and performance reviews.
