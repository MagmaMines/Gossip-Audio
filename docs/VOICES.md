# Neural voices and licensing

Speech runs on-device with sherpa-onnx, not Android system TTS. All current catalog model licenses permit commercial use without a model royalty, **subject to the terms below**. This is not a promise that generated audio is copyright-free, legally unrestricted, or suitable for every use: copyright and other rights in input text, third-party voices, output and local law can still apply. Check terms with counsel for distribution.

Earlier versions bundled Lessac (research/non-commercial restrictions) and offered Padmavathi (model license and training initialization unclear). **They are no longer available for new synthesis.** Audio generated with earlier versions remains subject to the original restrictions; changing the app does not retroactively change its rights. Existing private downloaded data may remain on a device after an update until app data is cleared.

The app checks pinned SHA-256 hashes and downloads only after confirmation. One Supertonic pack unlocks its nine languages; Kokoro is a separate large download and can require substantial storage and memory. Downloads contact GitHub/CDN, not a speech-generation server. Offline auto detection uses simple script and word clues, not a guaranteed language classifier: ambiguous or unsupported input must be selected manually, especially Han-only Chinese/Japanese or mixed languages. Model quality and pronunciation vary; test and listen on target devices.

Runtime, eSpeak NG phonemization data and other dependencies have separate licenses (including eSpeak NG GPL obligations). This debug build does not establish compliance with all app distribution duties; see [build instructions](BUILD.md) and [release readiness](RELEASE-READINESS.md).
