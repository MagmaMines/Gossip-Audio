# Voices

The packaged English Piper VITS model has multiple speaker IDs; the app exposes ten of them. The speaker IDs all run on CPU through sherpa-onnx. Voices are not Android system TTS and do not require downloading anything after installation. The app does not claim that these ten entries correspond to a particular gender, accent, nationality or emotion; preview them to choose.

This build supports English text only. It does not include Indian-language or Japanese models, voice cloning or GPU acceleration. Pitch shifting is not offered; style presets adjust speaking speed. Verify model and dataset licensing before commercial use.
